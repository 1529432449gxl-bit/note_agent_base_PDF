# 数学教材到 Obsidian 笔记

以 PDF 为内容依据，将教材的数学主干整理成与用户现有课程笔记相同风格的中文 Obsidian Markdown 文件。以准确和完整为先；不能读取或核对的地方明确标记并告知，不臆造。不能保证任意 PDF 都可完美识别；扫描件、图表、公式尤其须核对。

## 开始前

1. 确认 PDF 和已明确的范围、输出位置；未指定输出位置时，默认写入 PDF 所在课程目录，若可能覆盖已有文件则先检查并保留原文件。用户给了整本书而未限定范围时，以整本为目标，按章节分批处理；不擅自只交样章。页码同时区分 PDF 页码与印刷页码。文件巨大时持续处理、记录覆盖进度；必要时如实交代尚未完成的范围。
2. 先查看目标课程目录、同一课程的相邻笔记和已有 PDF。若用户有现成笔记库，优先参考其中的格式说明、绘图规范和最接近学科的两三份笔记。没有可用的参考笔记时使用 [references/conventions.md](references/conventions.md) 中的约定；用户本次要求优先。同课程已有风格优先于不同课程的范例。
3. 查看 PDF 目录、页数、页码偏移和文本层，确定各章节边界。建立章节与 PDF 页码的覆盖清单，标记已完成和未完成范围；逐章核对首末页及跨页续接。提取文本只是索引和初稿：对公式、上标下标、量词、表格、插图和识别可疑处渲染原页核对；扫描件逐页 OCR 并回看图像。不能读取时不要假称已经核对。

## 正文整理

- 按教材章节、节及必要的原有小标题组织，通常每章一个 `.md`，文件名沿用目标课程的命名。保留书中结构，不发明小节或以总结替代原文。章节标题形式跟随同课程笔记；无先例时使用 `# 第…章 …`、`## §… …`，必要时 `### …`。
- 收录定义、定理、引理、命题、推论、例题及其理解所必需的条件、公式、结论和关键上下文，忠实原意和次序。适度整理转写，不加入评述、闲聊、额外知识或凭空证明。默认保留例题题目及理解和复现结论所需的完整解法；以证明方法为章节主干时保留证明及关键推导。其他教材证明按同课程风格及用户要求处理。模型问题保留必要求解过程和推导，任何数学主干不得因压缩而丢失。核查证明中的正数、非负数、等号与分母不为零等条件；若原文疑似有误，保留可核对的原意并清楚注明问题与修正，不默改。对显然无法确认之处标注待核对，不猜测。
- 保留教材原有编号，形式如 `定义 1.1.1 正文`、`定理 1.2.3 正文`、`例 1.2.4 正文`；无编号时不捏造编号，局部笔记有明确约定则遵循。标题、段落和相邻条目之间留空行。普通叙述使用教材式平铺直叙，不加粗、不使用花哨 callout，不额外制作学习总结。
- 内联数学用 `$...$`，独立公式用独立行的 `$$`，教材搬运默认将独立公式放入 `aligned`，包括单行；同课程已有不同惯例或用户另有要求时按其惯例；`cases` 等环境照数学结构使用。不得使用 `\tag`；原文依赖公式编号的引用改写成清晰的文字指代，不能改变逻辑。保留原有数学符号、量词、定义域、假设和端点。
- 主动查找并重绘有助于理解的数学插图，在相关题目、定义或推导附近插入 Obsidian TikZJax 代码；即使正文已解释也不主动省略。逐图按 [references/conventions.md](references/conventions.md) 的绘图与核验规则处理；不能可靠重绘时使用清晰原页截图并标注待核对，避免遗漏或臆造。

## 校验与交付

按目录逐节核对覆盖，包括跨页的证明与命题；对照原页检查主干、编号、假设、公式、例题和图。整章范围包含章末习题时，将原题另存习题文件并完整核对，默认不添加解答；用户只要求正文或另有指示时按其要求处理。检查 Markdown 标题、美元符号及环境配对、无 `\tag`、文件名及跨章节续接。原 PDF 有文本提取不可靠、缺页或模糊时标明范围。修改已有笔记时保留无关内容，避免覆盖用户文件；输出 UTF-8 Markdown。最终给出可打开的文件链接，说明处理的页码/章节、验证方法和未核实处。

用户要求习题解答或单独生成图时，先读 [references/conventions.md](references/conventions.md) 的对应部分；不要将其自动混入教材笔记。
