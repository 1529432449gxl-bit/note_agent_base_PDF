# 笔记库约定与示例

参照用户现有数学课程笔记与其内容、绘图提示词总结。不同课程的标题和留白并不完全相同，先看目的目录，不要把示例的编号或内容照搬。

典型结构：

```markdown
# 第一章 复数与复变函数

## §1 复数

### 1. 复数域

定义 1.1.1 形如 $z=x+iy$ 的数称为复数，其中 $x,y\in\mathbb R$，$i^2=-1$。

定理 1.1.2 设……，则

$$
\begin{aligned}
a&=b+c,\\
d&=e.
\end{aligned}
$$
```

这只是版式示意，不是规定每章必须有三级标题。某些课程写 `# CH1 …`、`## sec1.1 …`，并在章首用引用块列记号约定；保持现有课程风格，仅在已有先例或用户要求时添加记号约定。主干内容不使用粗体，题注与正文放在同一段，行间公式无编号标签。原始提示同时存在“所有行间公式使用 aligned”和“多行时使用 aligned”两种写法；以课程成品和用户当次指令为准。

## 习题模式

仅在用户要求整理习题或补全解答时使用。读取对应课程文件夹、相关知识库和习题文件，依据所标教材和页码核对本地 PDF 原题，替换成准确 Markdown 并在原位置完整解答，保留无关内容。按原约定每节从（1）重新编号，写 `（1）题目正文`，空一行写 `解答：解答正文`。不新增标题、小节、列表或加粗，解答用数学系教材式的平铺叙述；内联单美元、行间双美元，不用 `\tag`。如果用户另行指定格式，以用户要求为准。

## TikZJax 图

数学关系优先，其次一次编译通过、构图和还原。识别坐标轴、区域、曲线、点、辅助线和标签；复杂图保留核心结构并主动简化。图采用 Obsidian TikZJax 0.5.2 代码块，内部使用 `\begin{document}` 和 `\begin{tikzpicture}`，不输出 documentclass 或 includegraphics。不使用外部文件、远程资源、HTML 或 JavaScript。优先基础路径、节点、显式坐标和箭头，避免需要复杂库的特效和交点运算。图内不用中文、Unicode 数学符号或全角标点；用 LaTeX 数学命令或简短英文。风格是深蓝主对象、橙色辅助对象、红色特殊点、灰色辅助线和浅色填充。检查环境、括号、数学模式、路径分号以及颜色和坐标定义。单独要求生成图代码时只返回一个完整 `tikz` 代码块；修错时保持结构并最小修改。仅在确有必要时使用 `amsmath`、`array`、`pgfplots`、`tikz-cd`、`circuitikz`、`chemfig`、`tikz-3dplot` 等已有提示词允许的包。

## 讲解模式

用户额外要求讲解时，可按“内容脉络—用大一数学分析知识解释—此处作为什么工具”组织。需要图解时，可用纯空格对齐、仅表头横线、无竖线和外框的 ASCII 表；流程图主流自上而下，用 `│`、`▼`、`─►` 等连接。此类讲解不是默认教材正文。


## 主动绘制与核验数学插图

处理每一页或每段视频时，主动查找和记录承载数学信息的图：包括集合图、几何示意、坐标系与函数图像、区域、箭头关系、图论结构和讲师手绘草图。即使文字已描述，只要原图有助于理解，默认在对应题目、定义或推导附近重绘；用户明确要求不绘图时例外。装饰图可省略。逐图记录原页码或真实时间、图所表达的内容以及已重绘、截图替代或待核对状态，检查覆盖，避免遗漏。

绘制前结合原页或连续视频画面和讲解识别对象、标签、交并补、包含、相交、相切、端点、方向和阴影等关系；同一视频的画面可能逐步添加或擦除，查看关键时刻，不把不同状态拼成虚构的原图。字幕不能作为图形的唯一依据。用户允许合理补充且确实有助理解时才画源材料没有的辅助示意，并注明是辅助示意，禁止把想象细节说成原图。

优先在笔记正文内使用 Obsidian TikZJax 的 `tikz` 代码块重绘，遵守本技能中 TikZJax 约定，按邻近文字位置插入并保持符号一致；无需另行请求用户指定绘图。对复杂的集合图，不得用几条普通圆弧声称表达实际上未画出的所有交并模式；优先可准确呈现的简化示意、拆成多图或使用真实画面。不要将 Venn 图中可表示的归属模式误说成实际集合都非空。若原图是曲线或几何构造，应保留关键点、相对位置及边界；数学准确优先于视觉完全相同。

先核对代码环境、路径分号、坐标和标签，再对照来源复核；如果本机有可用的 TikZJax/Obsidian 预览，实际渲染并检查可读性和遮挡，否则说明未能实测渲染，不声称编译通过。对于不可辨认或不能可靠重绘的图，优先嵌入清晰的原页裁图或视频截图作为替代，使用笔记相对路径并检查文件存在；标注对应原页或时间及待核对问题，不能以臆测图替代。图是辅助而非公式的替代，题目和关键公式仍须可检索。
